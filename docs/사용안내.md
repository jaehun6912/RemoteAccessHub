# 사용 안내

RemoteAccessHub는 집 밖에서 노트북으로 집 데스크톱에 접속하는 과정을 한 프로그램에서 진행합니다.

---

## 1. 준비물

| 항목 | 내용 |
| --- | --- |
| 노트북 | Windows 11 x64 |
| 런타임 | .NET 8 Desktop Runtime (x64), Microsoft Edge WebView2 Runtime |
| 공유기 | ipTIME (AX2004T / 펌웨어 15.36.6에서 확인) |
| 준비 | 공유기 WOL 목록에 데스크톱이 등록되어 있어야 합니다 |
| 크롬 원격 데스크톱 (선택) | 쓰려면 대상 PC에 호스트가 설치·로그인되어 있어야 합니다. 노트북에는 브라우저만 있으면 됩니다 |

두 런타임이 이미 설치되어 있는지 확인하려면 PowerShell에서 아래를 실행하세요.

```powershell
dotnet --list-runtimes | Select-String WindowsDesktop
```

WebView2 런타임은 최신 Windows 11에 기본 포함되어 있습니다. 없다면 Microsoft 공식 배포 페이지에서 "Evergreen Standalone Installer"를 설치하세요.

---

## 2. 첫 실행과 설정

`RemoteAccessHub.exe`를 처음 실행하면 **시작 설정** 창이 열립니다. 다섯 단계로 꼭 필요한 값만 받습니다.

| 단계 | 입력 | 참고 |
| --- | --- | --- |
| 1. 시작 | 없음 | 프로그램이 하는 일, 준비할 것, 저장하지 않는 것(아이디·비밀번호·보안문자) 안내 |
| 2. 공유기 주소 | 관리자 페이지 전체 주소 | [연결 확인]으로 그 주소·포트가 연결을 받는지 확인할 수 있습니다. https 주소일 때만 인증서 오류 허용을 고를 수 있습니다 |
| 3. 켤 PC | WOL 목록의 PC 이름, 필요하면 MAC | 이름이 비었거나 MAC 형식이 틀리면 다음으로 넘어가지 않습니다 |
| 4. 접속 방법 | 일반 접속(주소·외부 포트) / VPN 접속(Windows VPN 연결·내부 IP·포트) / 크롬 원격 데스크톱(기기 ID는 선택) | 쓰는 것만 켭니다. 일반 접속 주소에는 공유기 주소의 호스트가 미리 들어갑니다. 모두 끄면 [PC 켜기]만 쓸 수 있습니다 |
| 5. 확인 | 없음 | 입력 내용을 보여 주고 [완료]를 누르면 저장한 뒤 공유기 로그인 화면을 엽니다 |

- [나중에 설정]을 누르면 건너뜁니다. 시작 설정을 마치기 전까지는 실행할 때마다 다시 열립니다(⚙ 설정에서 공유기 주소와 PC 이름을 저장해도 마친 것으로 봅니다).
- 1.3.x 이하에서 이미 설정을 저장해 쓰던 경우에는 열리지 않습니다.
- 다시 하고 싶으면 ⋯ 메뉴의 **[시작 설정 다시 하기]** 를 누르세요.

아래는 ⚙ 설정 창의 모든 항목입니다.

### 공유기

| 항목 | 설명 | 예 |
| --- | --- | --- |
| 관리자 페이지 전체 URL | 프로토콜·주소·관리 포트를 모두 포함 | `http://내DDNS이름.iptime.org:8080/` |
| WOL 대상 PC 이름 | 공유기 WOL 목록에 보이는 이름과 **정확히** 같아야 함 | `MY-PC` |
| WOL 대상 MAC 주소 | 선택. 같은 이름이 여러 개일 때 구분용 | `00:11:22:33:44:55` |
| 공유기 인증서 오류 허용 | 공유기가 자체 서명 HTTPS일 때만 사용 | 기본 꺼짐 |

### 일반 접속 (DDNS 또는 공인 IP로 바로 RDP)

| 항목 | 설명 |
| --- | --- |
| RDP 접속 주소 | DDNS 이름 또는 공인 IP (포트는 아래에 따로) |
| RDP 외부 포트 | 공유기 포트포워딩의 외부 포트 |

### VPN 접속

| 항목 | 설명 |
| --- | --- |
| Windows VPN 연결 이름 | Windows 설정에 등록한 이름. 목록에서 고를 수 있습니다 |
| 데스크톱 내부 IP | VPN 연결 후 접속할 집 내부 IP |
| 내부 RDP 포트 | 보통 3389 |
| VPN 연결 대기 시간(초) | 기본 120 |

### 크롬 원격 데스크톱 (Chrome Remote Desktop)

구글 서버가 중계하므로 포트포워딩이나 VPN이 필요 없고, 대상 PC의 **실제 화면 세션에 붙기 때문에 모니터·해상도 제어가 그대로 동작합니다**(Windows RDP는 별도 세션을 만들어 모니터 제어가 막히는 경우가 있습니다). 기존 일반 접속·VPN 접속 기능은 그대로 남아 있습니다.

| 항목 | 설명 |
| --- | --- |
| 접속 방식에 '크롬 원격 데스크톱' 넣기 | 켜면 접속 방식 선택 창에 세 번째 항목이 생깁니다. 끄면 보이지 않습니다 |
| 기기 ID (선택) | `remotedesktop.google.com/access`에서 그 PC에 연결했을 때 주소의 `session/` 뒤 부분. 주소 전체를 붙여 넣어도 ID만 뽑아 씁니다. 비우면 기기 목록 화면을 엽니다 |
| 부팅 확인 방법 | `확인 안 함 (바로 열기)`(기본) / `일반 접속 주소·포트로 확인` / `VPN 연결 후 내부 IP·포트로 확인` |
| [기기 목록 열기] | 기기 목록 화면을 엽니다(앱이 있으면 앱으로). 여기서 기기 ID를 확인할 수 있습니다 |

- **대상 PC에 크롬 원격 데스크톱 호스트가 설치되어 있어야 합니다.** 구글 로그인과 PIN 입력은 브라우저에서 직접 하며, 프로그램은 어느 쪽도 대신 입력하거나 저장하지 않습니다.
- 크롬 원격 데스크톱은 열어 둔 포트가 없어 PC가 켜졌는지 확인할 방법이 없습니다. 확인하려면 위의 일반 접속 또는 VPN 설정을 빌려 쓰며(그 방식으로 **접속하지는 않고** 응답만 확인), 확인하지 않을 때는 ③ 단계에 "확인 안 함"이라고 표시합니다.
- 기기 ID는 16진수와 `-`만 받습니다. 형식이 어긋나면 주소에 넣지 않고 기기 목록 화면을 엽니다.

#### 앱으로 열기 / 브라우저로 열기

이 PC에 **Chrome 원격 데스크톱 앱이 설치되어 있으면 앱 창으로 열고, 없으면 기본 브라우저로 엽니다.** 따로 고르는 설정은 없고 자동으로 판단합니다. 지금 어느 쪽인지는 ⚙ 설정 > 크롬 원격 데스크톱 아래 설명과, 접속이 끝난 뒤 안내 줄에서 확인할 수 있습니다.

앱을 설치하려면 Edge나 Chrome에서 `remotedesktop.google.com/access`를 열고 주소창 오른쪽의 **[앱으로 설치]**(Edge) 또는 **[설치]**(Chrome)를 누릅니다. 설치하면 접속 방식 목록의 아이콘도 그 앱의 아이콘으로 바뀝니다(앱이 없으면 기본 아이콘).

| 상황 | 동작 |
| --- | --- |
| 앱이 설치됨 | 앱 창으로 열고, 저장한 기기 ID가 있으면 그 기기 화면까지 바로 엽니다 |
| 앱은 있는데 앱으로 주소를 넘기지 못함 | 앱 첫 화면(기기 목록)을 열고 "목록에서 기기를 고르세요"라고 알립니다 |
| 앱이 없음 | 기본 브라우저로 엽니다(지금까지와 같음) |

> 프로그램이 앱을 찾을 때는 Windows에 등록된 앱 목록만 읽습니다. 설정을 바꾸거나 앱을 설치·삭제하지 않습니다.

### PC 전원 상태 표시

윗줄 배지에 집 PC가 켜져 있는지 보여 줍니다. 크롬 원격 데스크톱처럼 부팅 확인을 하지 않는 방식으로 접속할 때 특히 쓸모 있습니다.

| 항목 | 설명 |
| --- | --- |
| 확인 방법 | `자동`(기본, VPN 연결 중이면 내부 IP·아니면 일반 접속 주소) / `일반 접속 주소·포트로만` / `VPN 연결 중일 때 내부 IP·포트로만` / `표시하지 않음` |
| 확인 주기(초) | 기본 60. 15~3600 |
| PC가 켜져 있으면 [PC 접속] 버튼을 천천히 깜빡이기 | 기본 켜짐 |

- 확인할 주소는 **위의 일반 접속·VPN 설정을 그대로** 씁니다. 둘 다 비어 있으면 배지가 보이지 않습니다.
- **확인하려고 VPN을 연결하지 않습니다.** VPN 확인은 이미 연결되어 있을 때만 합니다.
- 포트가 응답하면 켜진 것이 **확실**합니다. 응답이 없을 때는 꺼진 것인지 포트·방화벽 때문인지 구분할 수 없어 **"응답 없음"** 으로만 표시합니다.
- [PC 켜기]가 성공하면 20초 뒤에, 접속이 끝나면 곧바로 다시 확인합니다. 배지를 누르면 언제든 바로 확인합니다.
- PC 접속 작업이 진행 중일 때는 그 작업이 이미 포트를 확인하므로 배지 확인은 쉽니다.
- 배지가 **`PC 켜짐`일 때만** [PC 접속] 버튼이 2.2초 주기로 **서서히 밝아졌다 어두워지며** 바로 접속할 수 있다는 것을 알려 줍니다. `응답 없음`으로 바뀌거나 버튼을 누를 수 없는 동안에는 바로 멈추고 원래 색으로 돌아갑니다.

### 공통

| 항목 | 설명 |
| --- | --- |
| 부팅 대기 시간(초) | RDP 포트 응답을 기다리는 최대 시간. 기본 180 |
| 원격 데스크톱 전체 화면 | mstsc를 `/f`로 실행 |
| 로그인이 확인되면 공유기 화면 자동 접기 | 기본 켜짐. 로그인이 확인되는 즉시 접고 [관리도구] 선택은 접힌 채로 진행합니다. 자동으로 넘기지 못하면 다시 펼칩니다 |
| WOL 확인창 [확인] 자동 클릭 | 기본 켜짐(1.1.1부터). 1.1.0 이하에서 저장한 설정도 한 번 켜집니다. 끄면 확인창이 뜰 때 화면을 펼쳐 직접 누르게 합니다 |
| 로그인 직후 [관리도구] 자동 선택 | 기본 켜짐. 끄면 선택 화면에서 직접 누를 때까지 화면을 펼쳐 둡니다 |
| 테마 | Windows 설정 따르기(기본) / 어둡게 / 밝게. ⋯ 메뉴에서도 바꿀 수 있습니다 |

### 고급 (공유기 화면이 바뀐 경우에만)

| 항목 | 기본값 |
| --- | --- |
| WOL 페이지 경로 | `/ui/wol` (예전 설정의 `#/wol`은 자동으로 바뀝니다) |
| 관리도구 항목 이름 | `관리도구` |
| WOL 메뉴 그룹 이름 / 메뉴 이름 | `특수 기능` / `WOL 기능` |

> **공유기 관리 주소와 RDP 주소·포트는 서로 다른 항목입니다.** 한쪽이 비어 있어도 다른 쪽 기능은 막히지 않습니다. 접속할 때는 선택한 방식에 필요한 설정만 검사합니다.

### 설정 파일

| 버튼 | 동작 |
| --- | --- |
| 내보내기... | 설정 창의 현재 값을 JSON 파일로 저장합니다. 비밀번호·보안문자는 원래 저장하지 않으므로 들어가지 않습니다. 공유기 주소·PC 이름·VPN 이름이 들어 있으니 공유에 주의하세요. 창 위치는 빠집니다 |
| 가져오기... | 내보낸 파일의 값을 설정 창에 채웁니다. [저장]을 눌러야 적용됩니다. 이 프로그램의 설정 파일이 아니면 거부합니다 |
| 초기화... | 확인을 받은 뒤 모든 설정을 처음 상태로 되돌리고, 공유기 화면을 비운 뒤 시작 설정을 다시 엽니다. 기록 파일과 Windows VPN 연결은 그대로입니다 |

## 3. 화면 구성

```
┌ RemoteAccessHub ─────────────── [● 공유기 로그인됨] [● VPN 연결됨]  ⚙  ⋯  [✕ 종료] ┐
│ ① 공유기 로그인 ─── ② PC 켜기 ─── ③ 부팅 확인 ─── ④ 원격 접속                     │
│ ✓ 현재 상황 안내 (성공·진행·주의·오류에 따라 색이 바뀝니다)                         │
│ [▶ PC 켜고 접속] [⏻ PC 켜기] [PC 접속]                  [취소] [공유기 화면] [기록] │
└ (자세한 기록 — [기록]으로 열고 닫음) ────────────────────────────────────────────┘

┌ 공유기 화면 (별도 창 — 로그인이 확인되면 저절로 닫힘) ─────────────────────────┐
│ (공유기 관리자 페이지)                                                          │
└────────────────────────────────────────────────────────────────────────────────┘
```

| 영역 | 내용 |
| --- | --- |
| 상태 배지 | 공유기 로그인 상태, VPN 연결 상태, PC 전원 상태. VPN 배지는 설정에 VPN 이름이 있을 때만, 전원 배지는 확인할 주소가 있을 때만 보입니다. 전원 배지는 눌러서 바로 확인할 수 있습니다 |
| 단계 표시 | 네 단계를 대기(회색)·진행 중(파랑)·완료(초록)·주의(주황)·실패(빨강)로 보여줍니다. 부팅 확인은 대기 시간과 진행 막대가 함께 표시됩니다 |
| 안내 줄 | 지금 무엇을 하고 있는지, 무엇을 해야 하는지 알려 줍니다 |
| ⚙ | 설정 |
| 공유기 화면 창 | 공유기 관리자 페이지를 띄우는 **별도 창**입니다. 로그인이 확인되면 저절로 닫히고, 필요할 때 다시 열립니다. [공유기 화면](Ctrl+B)으로 직접 열고 닫을 수 있으며, 창의 ✕로 닫아도 로그인은 유지됩니다 |
| ⋯ | 공유기 창 다시 열기 · 현재 화면에서 PC 켜기 · 시작 설정 다시 하기 · 진단 내보내기 · 기록 폴더 열기 · 테마 |
| ✕ 종료 | 공유기 관리 세션을 로그아웃한 뒤 프로그램을 종료합니다 |

사용자 조작이 필요할 때(로그인 만료, [관리도구]나 [확인]을 직접 눌러야 할 때, 실패했을 때) 프로그램이 뒤에 있으면 **작업 표시줄 단추가 깜박입니다.**

## 4. 사용 순서

### PC가 꺼져 있을 때

1. 프로그램을 켜면 아래에 공유기 로그인 화면이 열립니다.
2. **아이디·비밀번호·보안문자를 직접 입력**하고 로그인합니다. 프로그램은 입력을 대신하지 않으며 읽거나 저장하지 않습니다.
3. 로그인이 확인되면 **공유기 화면 창이 곧바로 닫힙니다.** 닫힌 채로 [관리도구] / [설정마법사] 선택 화면에서 **[관리도구]를 자동으로 누릅니다.** 첫 누름에 반응이 없으면 잠시 뒤 다시 시도합니다(최대 3회). 끝내 넘어가지 못하면 창을 다시 띄워 직접 누르게 합니다.
   이 준비가 끝나 **"공유기 관리 화면이 준비됐습니다"** 가 뜰 때까지 [PC 켜고 접속]·[PC 켜기]·[PC 접속]은 눌리지 않습니다(상태 배지: "공유기 · 관리 화면 준비 중"). 준비가 실패로 끝나면 버튼은 다시 눌립니다.
4. **[▶ PC 켜고 접속]** 을 누르면 버튼 아래에 작은 선택 창이 뜹니다. **일반 접속**, **VPN 접속**, (설정에서 켠 경우) **크롬 원격 데스크톱** 중에서 고릅니다.
   - 마우스로 누르거나 숫자 **1 / 2 / 3**, 또는 **↑/↓ + Enter**로 고릅니다. **Esc**나 창 밖을 누르면 아무것도 하지 않고 닫힙니다.
   - 설정이 비어 있는 방식은 "설정 필요"로 표시되고 고를 수 없습니다.
   - 마지막으로 고른 방식에 미리 초점이 가 있습니다.
5. 고르면 아래 과정이 한 번에 진행됩니다.
   - WOL 화면으로 이동해 설정한 PC의 [PC 켜기]를 누르고, 확인창의 [확인]도 자동으로 누릅니다.
   - 공유기가 요청을 처리하면 RDP 포트가 응답할 때까지 기다립니다(부팅 확인).
   - 응답하면 Windows 원격 데스크톱을 실행합니다. 자격 증명은 Windows 창에서 입력합니다.
   - **크롬 원격 데스크톱**을 고른 경우에는 그 기기의 연결 화면을 엽니다(기기 ID가 없으면 기기 목록). 이 PC에 앱이 설치되어 있으면 앱 창으로, 없으면 기본 브라우저로 엽니다. 구글 로그인과 PIN 입력은 직접 하세요. 부팅 확인을 "확인 안 함"으로 두면 WOL 요청이 처리된 뒤 바로 엽니다 — PC가 아직 부팅 중이면 그 기기가 오프라인으로 보일 수 있으니 잠시 뒤 새로 고치세요.

PC 켜기가 실패하면 접속을 시도하지 않습니다.

### 나눠서 하고 싶을 때

- **[⏻ PC 켜기]**: PC만 켭니다.
- **[PC 접속]**: 누를 때마다 같은 선택 창이 뜹니다. 고른 방식으로 바로 접속합니다.

### PC가 이미 켜져 있을 때

**[PC 접속]** 만 누르면 됩니다. 공유기 로그인이나 WOL 없이 바로 연결합니다.

### 끝낼 때

| 방법 | 동작 |
| --- | --- |
| **[✕ 종료]** (Ctrl+Q) | 진행 중인 작업을 멈추고, 공유기 관리 세션을 **로그아웃**한 뒤 종료합니다. 로그아웃이 실제로 반영됐는지 공유기에 다시 물어 확인합니다. 확인되지 않으면 그래도 종료할지 묻습니다 |
| 창의 X 버튼 | 공유기 로그아웃 없이 닫습니다(세션은 공유기에서 시간이 지나면 만료). 작업 중이면 한 번 묻습니다 |

어느 방법이든 **VPN 연결은 끊지 않습니다.**

## 5. 단계 표시 읽는 법

| 단계 | 완료의 뜻 | 대표적인 표시 |
| --- | --- | --- |
| ① 공유기 로그인 | 공유기 API가 로그인 세션을 인정함 | `로그인됨 · 15:37` / `공유기 화면에서 로그인` / `[관리도구] 선택 필요` |
| ② PC 켜기 | 공유기가 WOL 요청을 **처리했다고 응답**함 | `WOL 화면으로 이동` / `확인창 [확인] 필요` / `대상 PC 없음` / `공유기 처리 완료 · 15:38` |
| ③ 부팅 확인 | 데스크톱의 RDP 포트가 **실제로 응답**함 | `VPN 연결 중` / `RDP 응답 대기 · 42/180초` / `응답 없음(시간 초과)` / `확인 안 함` |
| ④ 원격 접속 | 원격 데스크톱 또는 크롬 원격 데스크톱을 엶 | `원격 데스크톱 실행 · 15:39` / `크롬 원격 데스크톱 열림 · 15:39` |

②가 완료여도 PC가 켜졌다는 뜻은 아닙니다. 실제 부팅은 ③에서 확인합니다.

크롬 원격 데스크톱으로 부팅 확인 없이 접속하면 ③은 완료가 아니라 **`확인 안 함`** 으로 남습니다. 확인하지 않은 것을 확인한 것처럼 표시하지 않습니다.

공유기에 새로 로그인하면 이전 실행의 ②③④ 결과는 지워집니다(지난 결과가 "완료"로 남아 헷갈리지 않도록).

공유기 화면을 읽지 못해도 **로그아웃으로 판단하지 않습니다.** 로그인 상태는 공유기가 "인증되지 않음"이라고 답할 때만 해제됩니다.

### 단축키

| 키 | 동작 |
| --- | --- |
| Ctrl+Enter | PC 켜고 접속 (선택 창 열기) |
| Ctrl+Shift+Enter | PC 접속 (선택 창 열기) |
| Esc | 진행 중인 작업 취소 (VPN은 끊지 않음) |
| F5 | 공유기 화면 다시 열기 |
| Ctrl+B | 공유기 화면 창 열기/닫기 |
| Ctrl+L | 기록 보이기/숨기기 |
| Ctrl+Q | 공유기 로그아웃 후 종료 |

## 6. 문제 해결

### 로그인했는데 [PC 켜기]가 켜지지 않습니다

프로그램은 화면 모양이 아니라 공유기 API 응답(`session/info`)으로 로그인을 판정합니다.
`공유기: 로그인 필요`가 계속 보이면 로그인이 실제로 완료되지 않은 것입니다. 보안문자를 다시 확인하세요.

### 로그인했는데 공유기 창이 다시 열렸습니다

[관리도구]를 자동으로 누르지 못한 경우입니다. 상태 줄에 `[관리도구]를 눌러 주세요`가 보이면 그 창에서 직접 누르세요. 관리 화면이 확인되면 창은 다시 닫힙니다.
설정에서 [관리도구] 자동 선택을 끈 경우에는 처음부터 닫지 않고, 직접 누른 뒤 닫습니다.

공유기 화면이 다시 필요하면 [공유기 화면](Ctrl+B)으로 열 수 있습니다. 창을 닫아도 로그인 세션은 유지되며, 프로그램은 닫힌 동안에도 공유기 화면을 읽고 조작할 수 있습니다.
선택 화면이 아닌데도 창이 계속 열려 있다면 그 화면에서 [진단 내보내기]를 눌러 파일을 보내 주세요.

### WOL 화면으로 넘어가지 못합니다

왼쪽 메뉴에서 [특수 기능 → WOL 기능]을 직접 연 뒤 ⋯ 메뉴의 **[현재 화면에서 PC 켜기]** 를 누르세요.
프로그램은 메뉴를 누를 때 글자 위치와 그 지점의 항목 이름을 함께 확인합니다. 스크롤에 가려진 메뉴처럼 다른 항목(예: 로그아웃) 위에 걸친 위치는 누르지 않습니다.

### 대상 PC를 찾지 못한다고 나옵니다

- 설정의 PC 이름이 공유기 WOL 목록의 이름과 정확히 같은지 확인하세요. 메시지에 화면에서 보이는 이름이 함께 표시됩니다.
- 같은 이름이 여러 개면 설정에 MAC 주소를 입력하세요.
- 목록이 길어 대상이 화면 밖에 있으면 공유기 화면을 펼쳐 스크롤한 뒤 ⋯ 메뉴의 **[현재 화면에서 PC 켜기]** 를 누르세요.

프로그램은 대상을 특정하지 못하면 **아무 버튼도 누르지 않습니다.** 다른 PC가 잘못 켜지는 일은 없습니다.

### 자동 제어가 안 될 때

[공유기 화면]을 펼쳐 직접 `PC 켜기`를 누른 뒤 **[PC 접속]** 으로 진행하면 됩니다. 자동화 실패가 전체 흐름을 막지 않습니다.

### VPN이 연결되지 않습니다

저장된 자격 증명으로 먼저 시도하고, 실패하면 Windows VPN 연결 창을 띄웁니다. 추가 인증이 필요한 경우 그 창에서 입력하세요.
VPN이 실패해도 일반 접속으로 **자동 전환하지 않습니다.** 의도한 경로로만 접속합니다.

### 부팅 대기가 시간 초과됩니다

- 일반 접속: 공유기 포트포워딩과 외부 포트를 확인하세요.
- VPN 접속: 내부 IP와 내부 포트를 확인하세요.
- 데스크톱의 원격 데스크톱 허용과 방화벽 설정을 확인하세요.

### 원격 데스크톱으로 접속하면 모니터 설정을 바꿀 수 없습니다

Windows 기본 원격 데스크톱(mstsc)은 물리 화면과 별개의 세션에 연결하기 때문에, 실제 모니터의 전원·해상도·배치를 다루는 작업이 막히는 경우가 있습니다. 이럴 때는 **크롬 원격 데스크톱**으로 접속하세요. 대상 PC의 실제 화면 세션에 붙으므로 모니터 제어가 그대로 동작합니다.

⚙ 설정 > 크롬 원격 데스크톱에서 "접속 방식에 '크롬 원격 데스크톱' 넣기"를 켜면 접속 방식 선택 창에 항목이 추가됩니다. 일반 접속·VPN 접속은 그대로 남아 있으니 필요에 따라 골라 쓰면 됩니다.

### PC 전원 배지가 'PC 응답 없음'인데 PC는 켜져 있습니다

전원 배지는 설정한 주소·포트가 응답하는지만 봅니다. 응답이 없으면 꺼진 것인지, 포트포워딩·방화벽 때문인지 구분할 수 없어 "응답 없음"으로만 표시합니다.

- 일반 접속으로 확인한다면 공유기 포트포워딩과 외부 포트를, VPN으로 확인한다면 내부 IP와 포트를 확인하세요.
- 집 PC의 원격 데스크톱 허용과 방화벽 설정을 확인하세요.
- 켜져 있는지만 보고 싶고 열어 둔 포트가 없다면 ⚙ 설정에서 "표시하지 않음"으로 두는 편이 낫습니다. 잘못된 "응답 없음"이 계속 보이는 것보다 낫습니다.

### 크롬 원격 데스크톱이 앱이 아니라 브라우저로 열립니다

이 PC에 Chrome 원격 데스크톱 앱이 설치되어 있지 않은 경우입니다. Edge나 Chrome에서 `remotedesktop.google.com/access`를 열고 주소창 오른쪽의 [앱으로 설치]를 누른 뒤, ⚙ 설정 > 크롬 원격 데스크톱을 다시 열어 "앱이 설치되어 있어 앱 창으로 엽니다"로 바뀌었는지 확인하세요.

앱을 설치했는데도 브라우저로 열린다면 [기록]에 "크롬 원격 데스크톱 브라우저로 열기"가 남습니다. 그 줄과 함께 알려 주세요.

### 크롬 원격 데스크톱이 열렸는데 기기가 안 보입니다 / 오프라인입니다

- 대상 PC에 **크롬 원격 데스크톱 호스트**가 설치되고 로그인되어 있어야 합니다. 브라우저에서 보이는 구글 계정이 호스트를 설치한 계정과 같은지 확인하세요.
- PC가 아직 부팅 중일 수 있습니다. 잠시 뒤 브라우저를 새로 고치세요. 매번 기다리기 번거롭다면 ⚙ 설정의 **부팅 확인 방법**을 "일반 접속 주소·포트로 확인" 또는 "VPN 연결 후 내부 IP·포트로 확인"으로 바꾸면, 포트가 응답한 뒤에 브라우저를 엽니다(그 방식으로 접속하지는 않습니다).
- 기기 ID를 잘못 넣으면 그 기기로 바로 가지 못합니다. 모르면 비워 두세요. 비우면 기기 목록 화면이 열립니다.
- PIN을 잊었다면 기기 목록 화면에서 호스트 설정을 다시 하세요. 프로그램은 PIN을 저장하지 않으며 대신 입력하지도 않습니다.

### 로그인 직후 프로그램 창 위에서 마우스 커서가 안 보입니다

Windows의 "입력하는 동안 포인터 숨기기"가 켜져 있으면, 공유기 화면에 보안문자를 입력하는 동안 커서가 숨겨집니다. 1.3.2까지는 로그인 뒤 공유기 화면이 바로 접히면서 커서가 프로그램 창 위에서만 계속 안 보였습니다(창 밖에서는 보임).
1.3.3부터는 프로그램 창 위에서 마우스를 움직이면 다시 나타납니다. 그래도 안 보이면 [기록]을 캡처해 알려 주세요. 임시로는 설정 > Bluetooth 및 장치 > 마우스 > 추가 마우스 설정 > 포인터 옵션에서 "입력하는 동안 포인터 숨기기"를 끄면 생기지 않습니다.

## 7. 진단 파일

문제가 계속되면 진단 파일을 만들어 확인하세요.

- 문제가 난 **그 화면에서** [진단 내보내기]를 누르는 것이 가장 유용합니다. 화면 구조가 그대로 담깁니다.
- 1.0.0으로 만든 진단 파일에는 네트워크 기록과 로그에 공유기 DDNS 주소가 가려지지 않고 들어가는 문제가 있었습니다. 1.1.0부터 가립니다. 이전 진단 파일은 다른 곳에 공유하지 마세요.
- 로그인 없이 구조만 보려면 명령줄에서 실행합니다.

```powershell
.\RemoteAccessHub.exe --router-check "$env:USERPROFILE\Desktop\진단.json" --url "http://내DDNS이름.iptime.org:8080/"
```

진단 파일에는 **비밀번호·보안문자·쿠키·세션 토큰·원본 HTML이 들어가지 않습니다.** 주소와 MAC 주소는 일부가 가려집니다.
`--router-check`는 화면 캡처(`.png`)도 함께 저장합니다. 로그인 전 화면이라 입력값은 없지만, 공유 전에 내용을 한 번 확인하세요.

로그 파일 위치: `%LOCALAPPDATA%\RemoteAccessHub\logs`
설정 파일 위치: `%APPDATA%\RemoteAccessHub\settings.json`

## 8. 실행이 차단될 때

Windows가 실행을 막는다면 원인이 둘 중 하나입니다. 자세한 내용과 해결 방법은 [코드서명과배포.md](코드서명과배포.md)를 보세요.

- **SmartScreen**: "Windows의 PC 보호" 창. [추가 정보] → [실행]으로 진행할 수 있습니다.
- **Smart App Control**: 조용히 차단되며 우회 선택지가 없습니다. 신뢰된 코드 서명이 필요합니다.
